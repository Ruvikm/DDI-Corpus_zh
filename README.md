# DDI-Corpus

DDI-Corpus（Data Center Deployment Intent Corpus）是一个面向数据中心部署场景的高层业务意图语料库，用于研究自然语言业务需求向服务功能、资源配置及部署配置的转换过程。

当前仓库提供中文版数据集`DDI-Corpus_zh.xlsx`，共包含200条高层业务意图。

## 数据集内容

语料以数据中心业务系统部署为背景，系统名称及来源信息整理自公开网站，并在数据集中保留对应来源链接。

当前数据集包含：

- 200条高层业务意图
- 200个业务系统实体及对应来源链接
- 19类行业标签
- 18类技术部署维度

需求文本主要模拟业务人员或非技术人员提出部署需求时的表达方式。例如：

> 保证高峰期访问仍然顺畅。

> 隐藏真实地址并降低攻击面。

语料不会直接给出完整的端口、实例规格或服务功能顺序，需要根据业务目标和约束条件进一步完成技术配置推导。

## 数据构建

数据集主要从三个方面进行构建。

### 1. 业务系统实体

从公开网站整理具有实际业务背景的系统名称，并记录对应来源链接。数据覆盖政务、企业管理、数据库、中间件、安全、DevOps等场景。

### 2. 技术部署维度

结合GB/T 22239等标准及数据中心常见部署需求，整理18类技术部署维度：

- 防火墙访问控制
- 网络监测与镜像采集
- 负载均衡与健康检查
- 网关接入
- 流量整形与QoS
- 包分类与重定向
- CDN边缘盒子
- DNS解析与安全策略
- 应用代理/反向代理
- NAT地址转换
- DPI深度检测
- IDS/IPS入侵防御
- 缓存加速
- 会话控制/连接限速
- 密码机/加密设备接入
- IPSec隧道加密
- 传输中继/Relay
- 病毒扫描

每个业务系统根据其应用场景组合相应的技术部署维度。

### 3. 高层业务意图

在确定业务系统和技术部署维度后，将具体技术要求转换为业务目标和约束条件，尽量避免直接出现底层配置参数，使语料保留从业务语义向技术配置转换的过程。

## 数据字段

| 字段         | 说明                       |
| ------------ | -------------------------- |
| 序号         | 样本编号                   |
| 行业         | 业务系统所属类别           |
| 系统名称     | 业务系统名称               |
| 来源链接URL  | 业务系统公开来源           |
| 维度名称列表 | 当前样本涉及的技术部署维度 |
| 需求句子     | 高层业务意图文本           |
